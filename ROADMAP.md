# Roadmap

This is a direction, not a promise.

- Evaluate the focused AC experience with users and product teams.
- Add periodic cloud-state reconciliation; investigate MQTT realtime updates.
- Publish the first tagged release and container image workflow.
- Expand compatibility reports for additional Haier device families.
- Add safer backup and encrypted-state recovery guidance.
- Improve integration examples for local dashboards and voice assistants.

Non-goals: public internet hosting, hosted credential storage, and real appliance
commands from automated tests.
