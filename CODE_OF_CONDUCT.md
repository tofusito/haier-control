# Code of Conduct

We want Haier Control to be a welcoming, useful and technically honest project.

Participants are expected to be respectful, assume good faith, give actionable feedback,
and keep discussions focused on the project. Harassment, discrimination, personal attacks,
deliberate disclosure of private data and disruptive behavior are not acceptable.

Project maintainers may remove content or restrict participation when needed to keep the
community safe. Report concerns privately through the security contact described in
[SECURITY.md](SECURITY.md).
